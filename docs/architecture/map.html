Capture device

Local video or live camera.

Keep recent video in a local buffer. Send sampled images for assessment.

Monitoring service + AI

Apply rules, review evidence and create one incident for the ongoing event.

Video stays local until an alert requests a clip.

Confirmed incident starts two independent paths ↓

Notify now

Open app: incoming-alert screen with enabled sound.

Background: supported web push opens the incident.

Acknowledge on desktop or phone.

Save the event clip

Request footage around the event time. Preserve the lead-in and aftermath.

Upload to private server storage.

Preparing → uploading → ready, or unavailable.

Both paths meet at the same incident ↓

Replay and respond

Replay the saved clip on any authorized device. Review evidence, acknowledge ownership, dismiss an incorrect alert or resolve the event.

The initial notification does not wait for the video upload.
