Receive the incident, inspect evidence, acknowledge the alert, and choose its outcome.

Server → operator

Only confirmed incident clips are intended for server replay. The alert can arrive while the clip is still uploading.

The device owns capture, a rolling buffer, and the assessment loop. Model inference runs through an authenticated server relay; a browser does not hold an OpenAI key. The server owns shared incident state, alert routing, replay, and escalation. The operator can close their workspace without stopping the separate operational device. The current build has incomplete connections between assessment, reporting, and clip upload. The two planned demonstrations are a permitted crash replay and a safely staged fall with a consenting participant. Show only connected steps after a real run, and avoid promising universal camera support.
